# 🚀 Деплой Telegram Swiper в облако

Выберите платформу для деплоя вашего приложения и получите постоянную ссылку!

## 🎯 Вариант 1: Railway (Рекомендуется)

### Шаг 1: Зарегистрируйтесь на Railway
1. Откройте https://railway.app
2. Нажмите **"Login with GitHub"**
3. Разрешите доступ к вашим репозиториям

### Шаг 2: Создайте проект
1. Нажмите **"New Project"**
2. Выберите **"Deploy from GitHub repo"**
3. Найдите репозиторий **`Tgshka`** в списке
4. Нажмите на него

### Шаг 3: Дождитесь деплоя
Railway автоматически:
- ✅ Обнаружит конфигурацию `nixpacks.toml`
- ✅ Установит Python 3.11
- ✅ Установит все зависимости
- ✅ Запустит приложение

Деплой займет **2-5 минут**. Смотрите прогресс во вкладке **"Deployments"**.

### Шаг 4: Получите публичную ссылку
1. Откройте ваш проект в Railway
2. Нажмите на сервис (должен быть зеленым ✅)
3. Перейдите в **Settings** → **Networking**
4. Нажмите **"Generate Domain"**
5. Скопируйте вашу ссылку: `https://ваше-имя.up.railway.app`

### Шаг 5: Готово!
Откройте ссылку в браузере и пользуйтесь приложением!

**Бесплатный план Railway:**
- 500 часов в месяц
- $5 free credits ежемесячно
- HTTPS включен автоматически
- Достаточно для личного использования

## 🎯 Вариант 2: Render

### Шаг 1: Зарегистрируйтесь на Render
1. Откройте https://render.com
2. Нажмите **"Get Started"**
3. Войдите через GitHub

### Шаг 2: Создайте Web Service
1. На панели управления нажмите **"New +"**
2. Выберите **"Web Service"**
3. Выберите репозиторий **`Tgshka`**

### Шаг 3: Настройте сервис
Заполните поля:

- **Name**: `telegram-swiper` (или любое другое)
- **Region**: `Frankfurt (EU Central)` (или ближайший к вам)
- **Branch**: `claude/telegram-web-app-011CV4knLVxZVbV4RmwC1ukV`
- **Root Directory**: оставьте пустым (не заполняйте!)
- **Runtime**: `Python 3`
- **Build Command**: `pip install -r telegram_swiper_web/requirements.txt`
- **Start Command**: `cd telegram_swiper_web/backend && gunicorn --worker-class gevent --workers 1 --bind 0.0.0.0:$PORT app:app`

### Шаг 4: Создайте сервис
1. Нажмите **"Create Web Service"**
2. Render начнет деплой (3-7 минут)
3. Следите за логами во вкладке **"Logs"**

### Шаг 5: Получите ссылку
После успешного деплоя вы получите ссылку типа:
`https://telegram-swiper.onrender.com`

**Бесплатный план Render:**
- Бесплатно навсегда
- HTTPS автоматически
- Засыпает после 15 мин неактивности (первый запуск может быть медленным)

## 📱 Использование приложения

После деплоя на любой платформе:

1. **Откройте вашу ссылку** в браузере (на телефоне или компьютере)

2. **Получите API ключи Telegram:**
   - Перейдите на https://my.telegram.org
   - Войдите с вашим номером телефона
   - Перейдите в **"API development tools"**
   - Создайте приложение и скопируйте:
     - `api_id` (число)
     - `api_hash` (длинная строка)

3. **Авторизуйтесь:**
   - Введите API ID и API Hash
   - Нажмите "Сохранить и подключиться"
   - Введите номер телефона
   - Введите код из Telegram
   - Если у вас 2FA: введите пароль

4. **Готово!** Нажмите "Загрузить сообщения" и начните свайпать! 🎉

## 🐛 Проблемы?

### Railway:
- Откройте проект → Deployments → Выберите последний деплой → Logs
- Проверьте, что деплой завершился успешно (зеленая галочка)

### Render:
- Откройте ваш сервис → Logs
- Проверьте статус (должен быть "Live")

### Типичные ошибки:
- ❌ **"Module not found"** → Проверьте requirements.txt
- ❌ **"Port already in use"** → Перезапустите сервис
- ⚠️ **"cryptg install failed"** → Это нормально, не влияет на работу
