## Инструкция по деплою:

### 1. Зайдите на Railway
https://railway.app

### 2. Войдите через GitHub
Нажмите **"Login with GitHub"**

### 3. Создайте новый проект
1. Нажмите **"New Project"**
2. Выберите **"Deploy from GitHub repo"**
3. Найдите и выберите репозиторий **`Tgshka`**

### 4. Railway автоматически:
- Обнаружит `nixpacks.toml`
- Установит Python 3.11
- Установит зависимости из `telegram_swiper_web/requirements.txt`
- Запустит приложение командой из `Procfile`

### 5. Получите публичный URL
После успешного деплоя (2-3 минуты):
1. Перейдите в **Settings** → **Networking**
2. Нажмите **"Generate Domain"**
3. Получите URL типа: `https://your-app.up.railway.app`

### 6. Откройте приложение
1. Перейдите по вашему URL
2. Введите API ID и API Hash (получите на https://my.telegram.org)
3. Авторизуйтесь по номеру телефона
4. Готово! 🎉

## Логи

Если что-то пошло не так:
1. Откройте ваш проект в Railway
2. Нажмите на deployment
3. Выберите вкладку **"Logs"**
4. Посмотрите, что пошло не так

Типичные проблемы:
- **Port binding** - исправлено (app.py использует `PORT` из окружения)
- **Module not found** - проверьте, что все зависимости в requirements.txt
- **cryptg install error** - это нормально, приложение работает без него
