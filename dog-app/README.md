# 🐕 Dogee — приложение для владельцев собак

Мобильное веб-приложение (PWA), которое устанавливается на телефон как обычное приложение — без App Store и Google Play.

## Возможности

- **🌐 Все 24 официальных языка ЕС + русский** — язык определяется автоматически по настройкам телефона, переключается вручную на экране входа и в профиле. Поддерживаются: болгарский, хорватский, чешский, датский, нидерландский, английский, эстонский, финский, французский, немецкий, греческий, венгерский, ирландский, итальянский, латышский, литовский, мальтийский, польский, португальский, румынский, словацкий, словенский, испанский, шведский и русский.
- **👤 Регистрация и вход**:
  - **Apple ID** — кнопка «Войти через Apple»;
  - **Google / Gmail** — кнопка «Войти через Google»;
  - **почта со ссылкой-кодом** — вводите email, на него приходит письмо со ссылкой для входа (без пароля);
  - локальный аккаунт с email и паролем — работает всегда, даже без облака.
- **☁️ Хранение данных зарегистрированных** — при облачном входе все данные (питомцы, расходы, прививки) сохраняются в облачной базе (Firestore) и доступны с любого устройства. Локальная копия остаётся на телефоне, поэтому приложение работает и офлайн.
- **🐾 Профили питомцев** — кличка, порода, пол, дата рождения, вес, номер микрочипа. Возраст считается автоматически; если чипа нет — предупреждение (он обязателен для поездок по ЕС).
- **🌍 Страна питомца** — для каждого питомца выбирается страна ЕС (все 27), и во вкладке «Прививки» показываются правила именно этой страны: обязательна ли прививка от бешенства внутри страны, чипирование и регистрация, риск лейшманиоза, обработка от эхинококка перед въездом (Финляндия, Ирландия, Мальта), обязательная страховка ответственности (Испания и др.). В странах с высоким риском лейшманиоза эта вакцина автоматически попадает в план прививок. Названия стран переводятся на язык интерфейса автоматически.
- **💶 Дневник затрат** — 8 категорий, статистика за месяц и за всё время, диаграмма по категориям.
- **💉 Прививки и напоминания** — справочник прививок ЕС (WSAVA + Регламент ЕС № 576/2013), автогенерация плана по дате рождения, статусы «Просрочено / Сегодня / Через N дней», автосоздание напоминания о ревакцинации, уведомления, памятка о поездках по ЕС.

## Какие прививки знает приложение (ЕС)

| Вакцина | Статус | Схема |
|---|---|---|
| Бешенство (Rabies) | **Обязательна в ЕС** для поездок | с 12 недель, ревакцинация каждые 1–3 года |
| DHP (чума, гепатит, парвовирус) | Базовая (core, WSAVA) | 8, 12, 16 недель → 1 год → каждые 3 года |
| Лептоспироз | Рекомендована в ЕС | 8 и 12 недель → ежегодно |
| Парагрипп | Дополнительная | 8 и 12 недель → ежегодно |
| Бордетеллёз (вольерный кашель) | Дополнительная | ежегодно |
| Лейшманиоз | Юг ЕС | с 6 месяцев → ежегодно |

> ⚠️ Справочник носит информационный характер — точную схему всегда согласуйте с ветеринаром.

## Как запустить

### Вариант 1: GitHub Pages (рекомендуется)
1. В настройках репозитория: **Settings → Pages → Deploy from a branch**, выберите ветку и папку.
2. Откройте `https://<логин>.github.io/<репозиторий>/dog-app/` на телефоне.
3. Выберите в браузере **«Добавить на главный экран» / «Установить приложение»**.

### Вариант 2: локально
```bash
cd dog-app
python3 -m http.server 8000
# откройте http://localhost:8000
```

## Как включить облачные аккаунты (Apple ID / Google / почта)

Пока облако не настроено, приложение честно показывает это на экране входа и работает с локальными аккаунтами. Чтобы включить настоящий вход через Apple ID, Google и почту:

1. Создайте бесплатный проект на [console.firebase.google.com](https://console.firebase.google.com).
2. Добавьте Web-приложение и скопируйте `firebaseConfig` в файл `firebase-config.js` (там есть подробная инструкция и пример).
3. В **Authentication → Sign-in method** включите Google, Email link и Apple.
   - ⚠️ Для Apple ID нужен платный аккаунт Apple Developer (99 $/год) — это требование Apple, без него кнопка Apple работать не будет. Google и почта — бесплатно.
4. В **Authorized domains** добавьте домен приложения (например, `ваш-логин.github.io`).
5. Создайте **Firestore Database** и вставьте правила доступа из `firebase-config.js` (каждый пользователь видит только свои данные).

После этого на экране входа появятся кнопки Apple ID, Google и «Прислать ссылку для входа на почту», а данные пользователей будут храниться в облаке и синхронизироваться между устройствами.

## Хранение данных

- **Облачный аккаунт**: данные в Firestore (документ `users/<uid>`), доступ только у владельца аккаунта; на устройстве хранится офлайн-копия.
- **Локальный аккаунт**: данные в `localStorage` устройства, пароль — в виде SHA-256-хэша.
- В профиле есть «Экспорт данных (JSON)» для резервной копии.
