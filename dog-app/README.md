# 🐕 ДогКеа — приложение для владельцев собак

Мобильное веб-приложение (PWA), которое можно установить на телефон как обычное приложение — без App Store и Google Play.

## Возможности

- **👤 Регистрация владельца** — аккаунт с именем, email и паролем (данные хранятся локально на устройстве, пароль — в виде SHA-256 хэша).
- **🐾 Профили питомцев** — кличка, порода, пол, дата рождения, вес, номер микрочипа. Приложение само считает возраст и предупреждает, если нет чипа (он обязателен для поездок по ЕС).
- **💶 Дневник затрат** — расходы по категориям (корм, ветеринар, лекарства, груминг, игрушки, амуниция, страховка), статистика за месяц и за всё время, диаграмма по категориям.
- **💉 Прививки и напоминания**:
  - встроенный **справочник прививок для собак в ЕС** (рекомендации WSAVA и Регламент ЕС № 576/2013);
  - автоматическая **генерация плана прививок** по дате рождения щенка (бешенство, DHP, лептоспироз, парагрипп);
  - напоминания с бейджами «Просрочено / Сегодня / Через N дней»;
  - при отметке «Выполнена» автоматически создаётся напоминание о следующей ревакцинации;
  - push-уведомления при открытии приложения (за 7 дней до прививки);
  - памятка о правилах поездок с собакой по ЕС (чип → прививка от бешенства → 21 день ожидания → паспорт ЕС).

## Какие прививки знает приложение (ЕС)

| Вакцина | Статус | Схема |
|---|---|---|
| Бешенство (Rabies) | **Обязательна в ЕС** для поездок | с 12 недель, ревакцинация каждые 1–3 года |
| DHP (чума, гепатит, парвовирус) | Базовая (core, WSAVA) | 8, 12, 16 недель → 1 год → каждые 3 года |
| Лептоспироз | Рекомендована в ЕС | 8 и 12 недель → ежегодно |
| Парагрипп | Дополнительная | 8 и 12 недель → ежегодно |
| Бордетеллёз (вольерный кашель) | Дополнительная (передержки, выставки) | ежегодно |
| Лейшманиоз | Юг ЕС (Испания, Италия, Португалия, Греция) | с 6 месяцев → ежегодно |

> ⚠️ Справочник носит информационный характер — точную схему всегда согласуйте с ветеринаром.

## Как запустить

### Вариант 1: GitHub Pages (рекомендуется)
1. В настройках репозитория включите **Settings → Pages → Deploy from a branch**, выберите ветку и папку.
2. Откройте ссылку вида `https://<логин>.github.io/<репозиторий>/dog-app/` на телефоне.
3. В браузере выберите **«Добавить на главный экран» / «Установить приложение»** — иконка появится как у обычного приложения, работает офлайн.

### Вариант 2: локально
```bash
cd dog-app
python3 -m http.server 8000
# откройте http://localhost:8000
```

## Хранение данных

Все данные хранятся в `localStorage` браузера на вашем устройстве и никуда не отправляются. В профиле есть кнопка «Экспорт данных (JSON)» для резервной копии.
